# Project Documentation

This directory contains comprehensive documentation for the PHP MVC framework project.

## Structure

- `@docs/posts/` - Blog post planning and drafts organized by feature branch
- `@docs/api/` - API documentation (future)
- `@docs/guides/` - User guides and tutorials (future)
- `@docs/architecture/` - Architecture documentation (future)

## Blog Posts

Blog posts are organized by feature branch in the `posts/` directory:

- Each feature branch gets its own subdirectory
- Contains planning documents and draft posts
- Posts directory is excluded from Git (see .gitignore)
